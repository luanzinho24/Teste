API
URL exata da API de conexão https://api.exemplo.com/v1/lua/connect
Método HTTP utilizado POST
Formato JSON esperado 
{
  "clientId": "string",
  "deviceId": "string",
  "sessionId": "string",
  "status": "online",
  "lastSeen": "2026-11-01T12:00:00Z"
}
Endpoint para buscar configurações GET /v1/lua/config?clientId={clientId}
Endpoint para atualizar heartbeat do cliente POST /v1/lua/heartbeat
Endpoint para consultar status online/offline GET /v1/lua/status?clientId={clientId}
Intervalo recomendado de sincronização 30 segundos

Observações de segurança

Tokens e credenciais permanecerão armazenados apenas na sessão do navegador e nunca serão expostos no frontend desta tela.
